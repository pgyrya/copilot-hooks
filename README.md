# Effective Agentic Development with Copilot

The objective of this repo is to share best practices around how we can make local agentic development with Copilot more effective.

It has grown out of initial frustration with agentic systems claiming the work is done when it is anything but done.

The objective is then to learn to effectively outsource significant volume of cognitive work to even locally deplouyed LLM models in the context of using Copilot in an autopilot mode.

This repo contains [general copilot instructions](./copilot-instructions.md), along with hooks designed to re-focus the attention of the agent after key events in a way that improves results.
